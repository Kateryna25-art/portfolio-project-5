Tech Stack
 PHP (WordPress Custom Theme Architecture, Dynamic Loops, Functions & Hooks)
 Custom Fields & Settings: Advanced Custom Fields (ACF), WP Customizer API
 HTML5 / CSS3 / SCSS (Modular SCSS architecture: Abstracts, Base, Components, Layout, Pages, Sections)
 JavaScript (Vanilla JS): Custom mobile menu toggle & DOM interactions
 Assets & Performance: Self-hosted WOFF2 fonts, SVG icons
 Version Control: Git & GitHub
Theme Architecture & Key Features
 Dynamic PHP Templates: Custom headers, footers, post single views, category archives, author pages, and index layouts
 Modular SCSS Architecture: Clean file abstraction into abstracts (_mixins.scss, _variables.scss), base, components, and page-specific styles
 Extended Functionality: Custom post types and field structures organized in modular PHP files (inc/acf.php, inc/post-types.php, inc/customizer.php)
 Responsive UI: Mobile-first navigation and layout components adapted for all screen sizes
